# v2.3.0

First public stable release of Illustrator Artboard Compiler.

Combines artboards from multiple Illustrator files into one editable master Illustrator document while preserving artboard dimensions and artwork positioning.

### Highlights

- Editable Illustrator objects
- Exact artboard sizes
- Source-file ordering before compile
- Parent layer per imported file
- Sublayer per artboard
- Matching layer colors within each imported file
- Mixed RGB/CMYK warning
- Up to Illustrator's 100-artboard document limit
